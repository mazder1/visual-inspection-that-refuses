What comes back

  
One JSON response per part, built to be audited rather than believed.

  

    
mask_png_base64
Localised defect mask

      
Pixel-level segmentation at 512×512 from a 2.16M-parameter U-Net implemented
      from the paper — returned inline as a few-KB PNG.

    
probability_defective
Calibrated probability

      
Isotonic calibration on held-out outcomes: when the system says ~95%, the
      observed rate is ~100%. Pooled Brier 0.019 vs 0.15 for guessing the base rate.

    
verdict: "no-call"
An explicit refusal

      
Weak, conflicting, or never-seen-before evidence is routed to a human instead
      of being forced into yes/no. The flag fires on 76% of novel defects vs 8% of clean parts.

    
mc_passes: 20
Uncertainty, measured

      
The network runs 20 times with dropout live; where the passes disagree, the
      model is guessing — and per-region persistence records exactly how much.

    
provenance
Auditable to the split

      
Every response carries the SHA-256 of the leakage-aware data split and the
      checkpoint it was measured on. A number can never be quietly reattributed.

    
probability_is_supported
No extrapolated confidence

      
If a score lands where the calibrator has no validation data, the response
      says so — and the verdict becomes a no-call rather than a guess.

  






  
How it works

  
Four stages, each one measured before the next was built.

  

    
Segment
A from-scratch U-Net predicts per-pixel defect
    probability. GroupNorm, bilinear upsampling, 512×512, trained per category on a
    component-grouped split so the same physical part never straddles train and test.

    
Sample
20 forward passes with Monte-Carlo dropout give a
    mean map and a disagreement map — the model's own uncertainty, per pixel.

    
Score regions
Evidence is scored as connected regions
    (log-odds mass, hysteresis at 0.33/0.5) — a defect is a contiguous thing, and
    scattered specks cannot be one.

    
Calibrate & decide
An isotonic staircase fitted on
    validation outcomes turns the score into a probability; support gaps, a mid-band,
    and a weak-evidence floor turn doubt into an explicit no-call.
